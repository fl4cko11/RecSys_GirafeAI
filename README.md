# Персональные top-10 рекомендации

**Студент:** Хомяков Владислав Андреевич.

**Датасет:** [Amazon Reviews 2023](https://amazon-reviews-2023.github.io/), категория **Video Games**. Данные получены из [официального репозитория McAuley Lab на Hugging Face](https://huggingface.co/datasets/McAuley-Lab/Amazon-Reviews-2023) с закреплённой ревизией `2b6d039ed471f2ba5fd2acb718bf33b0a7e5598e`.

Из 4 624 615 исходных отзывов после очистки и отбора по train сформирована выборка из **429 302 взаимодействий, 51 846 пользователей и 5 974 товаров**. Порядок отбора, контрольные суммы исходных файлов и статистика каждого этапа приведены в ноутбуке. Сами данные в репозиторий не включены.

## Состав работы

- `experiments.ipynb` — выполненный лабораторный отчёт: постановка задачи, загрузка, EDA, подготовка данных, формулы, подбор параметров, итоговые таблицы, графики и выводы.
- `models/item_knn.py` — ItemKNN с cosine similarity и shrinkage.
- `models/ials.py` — ALS для неявной обратной связи.
- `models/ease.py` — EASE с аналитическим решением.
- `models/fm.py` — факторизационная машина с категориями и брендом товара.
- `models/custom_als.py` — ALS с целевым сигналом `(rating − 3) / 2`.
- `experiment_utils.py` — загрузка, подготовка, кодирование признаков и общий оценщик.
- `requirements.txt` — закреплённые зависимости.

Обучение, предсказания и рекомендации реализованы самостоятельно с использованием NumPy, SciPy и PyTorch.

## Протокол и результаты

Использовано глобальное временное разбиение train/validation/test. Релевантен товар с будущей оценкой **4 или 5**. Основная метрика для выбора параметров — **NDCG@10**, дополнительные — Recall@10 и Coverage@10. Для всех моделей одинаковы пользователи, полный каталог кандидатов и исключение ранее оценённых товаров. После выбора параметров по validation модели переобучены на train + validation; итоговая оценка проведена на test.

| Модель | NDCG@10 | Recall@10 | Coverage@10 |
|---|---:|---:|---:|
| EASE | 0.020399 | 0.033530 | 0.217944 |
| ItemKNN | 0.017809 | 0.030070 | 0.378306 |
| iALS | 0.016717 | 0.029653 | 0.093405 |
| CustomALS | 0.015323 | 0.024988 | 0.088216 |
| FM без метаданных | 0.013576 | 0.022263 | 0.126883 |
| FM с метаданными | 0.010919 | 0.018369 | 0.081185 |

Лучший результат по NDCG@10 и Recall@10 получил EASE. Добавление метаданных и изменение таргета ALS не улучшили точечные оценки; парные bootstrap-интервалы разницы включают ноль. Подробные параметры и ограничения приведены в ноутбуке.

Зафиксированы seed `42`, версии библиотек, ревизия источника, правила отбора, временные границы и порядок разрешения одинаковых scores. Метаданные даны одним снимком: их историческая неизменность является допущением эксперимента. Результаты относятся к выбранному warm-start протоколу и подвыборке.
